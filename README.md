# Project Rocky

Building Rocky from *Project Hail Mary* on a $300 budget.

## About

Three friends went to the theaters and watched *Project Hail Mary*. We were amazed by Rocky and decided to challenge ourselves to build our own version of him for $300.

What started as an idea between friends has turned into an ongoing robotics project. We are working with electronics, CAD, and programming to bring Rocky to life while learning along the way.

Our goal is not just to build Rocky, but to document the process so others can build their own version of him.

## Current Status

We are currently working on Version 1 of Rocky. This repository contains the code and CAD files we are using for the current build.

The project is still in development, so these files may change as we test our designs and make improvements. We have not finished the robot or the full build guide yet.

Once the build is complete, we plan to put together a detailed guide covering the entire process, from purchasing components to assembling the robot and getting the code running.

## Hardware and Software

Our current build uses the following components and technologies:

- ESP32 for embedded control
- PCA9685 for servo control
- Servo motors for mechanical movement
- CAD files for designing the robot's structure

The code and CAD files in this repository reflect our current progress.

## Repository Contents

- `firmware/` contains the code used for the robot.
- `hardware/` contains our CAD files and other design resources.
- `docs/` will contain documentation as the project develops.

The repository structure and files may change as we continue working on Rocky.

## Future Plans

Once we finish building and testing Rocky, we plan to publish a complete build guide that includes:

- A full list of components, prices, and purchase links
- CAD files and assembly instructions
- Wiring diagrams and electronics setup
- Power system setup
- Code installation and configuration
- Step by step building instructions
- Testing and troubleshooting
- A final breakdown of the project budget

We want the guide to be detailed enough for someone else to follow and build their own version of Rocky without having to figure everything out from scratch.

## Budget

Our target budget is $300. So far, we have spent $227, leaving us with $73 for the rest of the build.

We will continue tracking our expenses and share the final breakdown once the project is complete.

## Why We Are Building Rocky

We are three friends who watched a movie and decided to try building something we thought was incredibly cool.

None of us had the entire process figured out from the beginning. We are learning by designing, programming, testing, and improving our work.

We hope that by sharing our code and CAD files now, and publishing a complete guide when we finish, we can help other people take on similar projects of their own.

## Follow the Project

Rocky is still a work in progress. We will continue updating this repository as we develop the robot.

For now, you can explore the code and CAD files we are using. Once the build is complete, we will add the full step by step guide so anyone interested can follow along and build their own Rocky.
